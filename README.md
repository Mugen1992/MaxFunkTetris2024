# MaxFunkTetris2024

## Краткое описание
MaxFunkTetris2024 - консольная версия классического Тетриса на C#/.NET. Проект демонстрирует принципы ООП и работу с консольным интерфейсом без использования графических фреймворков. Управление осуществляется только с клавиатуры, рендеринг выполнен средствами стандартной консоли.

## Особенности
- Все классические фигуры тетрамино.
- Поворот, перемещение и проверка коллизий.
- Очистка линий, подсчёт очков и уровней.
- Консольный UI в тёмной цветовой гамме в стиле терминала (тёмный фон, серые точки-сетка, жёлто-оранжевые акценты).
- Простой, но эффективный рендеринг без сторонних библиотек.

## Как играть
1. Запустите проект командой `dotnet run` из корня репозитория.
2. Цель - заполнять горизонтальные линии без зазоров, чтобы очищать их и получать очки.
3. Игра заканчивается, когда новая фигура не может быть размещена на поле.

### Controls
- Стрелки `←` / `→` - перемещение фигуры влево/вправо.
- Стрелка `↑` - поворот фигуры.
- Стрелка `↓` - ускоренное падение.
- `P` - поставить игру на паузу и продолжить.
- `Esc` - вернуться в главное меню из паузы/подсказок.
- В меню: `↑` / `↓` для выбора пунктов, `Enter` - подтвердить.

### Difficulty
Сложность настраивается в меню **Settings** и влияет на скорость падения фигур (шаг падения - количество кадров, один кадр ≈ 30 мс):
- **Easy** - 10 кадров между шаго́м падения (≈300 мс, больше времени на реакцию).
- **Normal** - 6 кадров (≈180 мс, базовый режим).
- **Hard** - 3 кадра (≈90 мс, максимальная скорость).

### Минимальный размер консоли
Рекомендовано окно не меньше **80×30** символов, чтобы вся рамка поля, панели статистики и экраны меню влезали без обрезания.

## Структура кода
- **Tetromino** - модели фигур, форма, координаты, вращение.
- **GameBoard** - игровое поле: сетка, коллизии, очистка линий.
- **GameRenderer** - отрисовка поля и интерфейса в консоли.
- **Game** - игровой цикл, генерация фигур, обработка ввода.
- **ConsoleTheme** / **GameState** - (при наличии) палитра консоли и состояния игры.

## Установка и запуск
- Запуск из исходников:
  ```bash
  dotnet run
  ```
- Сборка релиза и запуск исполняемого файла:
  ```bash
  dotnet publish -c Release
  # бинарник можно запустить из папки bin/Release/net8.0/publish
  ```
- Требуется .NET 8.0 (см. `MaxFunkTetris2024.csproj`).
