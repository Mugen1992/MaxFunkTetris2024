# MaxFunkTetris2024

## Краткое описание
MaxFunkTetris2024 — консольная версия классического Тетриса на C#/.NET 8. Игровая логика, UI и тесты собраны в одном минимальном репозитории: управление только с клавиатуры, рендеринг реализован средствами стандартной консоли без внешних библиотек и без мерцания экрана.

## Особенности
- Все классические фигуры тетрамино, вращение, перемещение и проверка коллизий.
- Очистка линий, подсчёт очков и уровней, переход в Game Over при заполнении верхней части поля.
- Консольный UI в тёмной цветовой гамме, анти-фликер рендер без `Console.Clear()` в игровом цикле.
- Стейт-машина экранов: MainMenu → Playing → Paused → GameOver, плюс Help и Settings.
- Настройки сложности (Easy/Normal/Hard) меняют скорость падения фигур.
- Встроенные автотесты на xUnit + GitHub Actions workflow `.NET CI` (build + test).

## Требования и запуск
- Требуется **.NET 8** (см. `MaxFunkTetris2024.csproj`).
- Рекомендуемый минимальный размер консоли: **80×30** символов. При старте выводится предупреждение, если окно меньше.
- Кодировка вывода: UTF-8 (`Console.OutputEncoding = UTF8`).

### Запуск игры
```bash
dotnet run
```

### Запуск тестов
```bash
dotnet test ./MaxFunkTetris2024.Tests/MaxFunkTetris2024.Tests.csproj
```

## Как играть
1. Запустите `dotnet run` из корня репозитория.
2. Цель — заполнять горизонтальные линии без зазоров, чтобы очищать их и получать очки.
3. Игра заканчивается, когда новая фигура не может быть размещена на поле.

### Controls
- Стрелки `←` / `→` - перемещение фигуры влево/вправо.
- Стрелка `↑` - поворот фигуры.
- Стрелка `↓` - ускоренное падение.
- `P` - поставить игру на паузу и продолжить.
- `Esc` - вернуться в главное меню из паузы/подсказок.
- В меню: `↑` / `↓` для выбора пунктов, `Enter` - подтвердить.

### Экранная навигация
- **MainMenu** — запуск игры, открытие Help/Settings, выход.
- **Help** — краткие подсказки по управлению.
- **Settings** — выбор сложности (Easy/Normal/Hard).
- **Paused** — ставится по `P`, есть подсказки по возврату.
- **GameOver** — отображает финальный счёт и даёт вернуться в меню.

### Difficulty
Сложность настраивается в меню **Settings** и влияет на скорость падения фигур (шаг падения — количество кадров, один кадр ≈ 30 мс):
- **Easy** - 10 кадров между шагами падения (≈300 мс, больше времени на реакцию).
- **Normal** - 6 кадров (≈180 мс, базовый режим).
- **Hard** - 3 кадра (≈90 мс, максимальная скорость).

### Минимальный размер консоли
Рекомендовано окно не меньше **80×30** символов, чтобы вся рамка поля, панели статистики и экраны меню влезали без обрезания. При меньшем размере выводится предупреждение перед запуском игры.

## Структура репозитория
- Корень: `Program.cs` с игровой логикой, стейт-машиной экранов и анти-фликер рендером; `MaxFunkTetris2024.csproj` и `.sln`.
- Тесты: `MaxFunkTetris2024.Tests/` с xUnit- тестами (`TetrominoTests`, `GameBoardTests`, `GameLogicTests`, `GameStateMachineTests`, `SmokeTests`).

## Установка и запуск
- Запуск из исходников:
  ```bash
  dotnet run
  ```

  Для релизов доступен таргет под .NET 8, дополнительных зависимостей нет.
